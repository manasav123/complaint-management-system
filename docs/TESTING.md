\# Testing Checklist



\## 1. Frontend Testing



\### Registration

\- \[ ] Registration page opens correctly

\- \[ ] Name field accepts valid input

\- \[ ] Email field accepts valid email

\- \[ ] Password field accepts valid password

\- \[ ] Required-field validation works

\- \[ ] Invalid email validation works

\- \[ ] Successful registration gives proper feedback



\### Login

\- \[ ] Login page opens correctly

\- \[ ] Email validation works

\- \[ ] Password validation works

\- \[ ] Empty fields are handled

\- \[ ] Invalid login is handled properly

\- \[ ] Successful login works



\### Complaint Submission

\- \[ ] Complaint form opens correctly

\- \[ ] Required fields are validated

\- \[ ] Complaint can be entered

\- \[ ] Form handles invalid input

\- \[ ] Successful submission gives proper feedback



\## 2. Navigation Testing



\- \[ ] Home page navigation works

\- \[ ] Login navigation works

\- \[ ] Registration navigation works

\- \[ ] Complaint page navigation works

\- \[ ] Logout/navigation links work where implemented

\- \[ ] No broken routes



\## 3. Backend API Testing



\- \[ ] Backend server starts successfully

\- \[ ] Health API responds successfully

\- \[ ] Registration API accepts valid data

\- \[ ] Registration API rejects invalid data

\- \[ ] API returns expected response

\- \[ ] API errors are handled properly



\## 4. Frontend-Backend Integration



\- \[ ] Frontend can communicate with backend

\- \[ ] Registration form sends data to API

\- \[ ] API response is handled correctly

\- \[ ] API errors are displayed properly

\- \[ ] CORS works correctly

\- \[ ] No unexpected console errors



\## 5. Database Testing



\- \[ ] Database connection works

\- \[ ] User data is stored correctly

\- \[ ] Duplicate email is handled

\- \[ ] Stored data matches submitted data



\## 6. Final Testing



\- \[ ] Application starts without errors

\- \[ ] Main user flow works

\- \[ ] No major console errors

\- \[ ] No broken pages

\- \[ ] Changes are committed to Git

\- \[ ] Changes are pushed to GitHub
