\# Team Work Distribution



\## Project

AI-Powered Complaint Management System



\## Team Member 1 — Frontend



Responsibilities:

\- React.js frontend setup

\- User interface and page design

\- Navigation and routing

\- Registration and login forms

\- Complaint submission form

\- Form validation

\- Frontend user experience

\- Frontend pages required by the project



\## Team Member 2 — Backend and Database



Responsibilities:

\- FastAPI backend setup

\- PostgreSQL database setup

\- Database connection

\- Database models

\- Backend API development

\- User registration API

\- Authentication and authorization

\- Complaint-related APIs

\- Backend validation and error handling



\## Team Member 3 — Integration, Testing and GitHub



Responsibilities:

\- Frontend-backend integration

\- API integration using Axios

\- Integration testing

\- Functional testing

\- API testing

\- Checking frontend and backend communication

\- Identifying and reporting bugs

\- Git and GitHub project coordination

\- Branch management

\- Maintaining testing documentation

\- Maintaining project documentation

\- Final integration verification



\## Development Workflow



1\. Each team member works on their assigned responsibilities.

2\. Team members use separate Git branches for their work.

3\. Changes are committed with clear commit messages.

4\. Changes are pushed to GitHub regularly.

5\. Changes are reviewed before merging into the main branch.

6\. Integration testing is performed after frontend and backend components are ready.
